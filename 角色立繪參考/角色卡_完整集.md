## 01. 言衡（主角）

### 基本資料
- **姓名**：言衡（Yan Heng）
- **族裔**：人族（後期揭示有靈族血統）
- **年齡**：22→24→26（三部曲對應）
- **生日**：律紀元 178 年・春分
- **出生地**：玄律城・北區
- **職業**：辯護律師
- **所屬**：雲息律所（Game 1）→ 自立門戶（Game 2 後）

### 外型
- **身高**：175cm（普通偏高）
- **體型**：纖瘦但不弱，書生體格
- **髮**：黑色短髮，側分瀏海
- **眼**：深棕色，銳利但帶暖意
- **膚**：白皙
- **服裝**：
  - **常服**：深藍色中華風律師袍，銀邊，左胸繡「衡」
  - **休閒**：素白裡衣 + 灰布外袍
  - **正裝（後期）**：金線繡的守護者法袍

### 個性
- **MBTI**：INFJ（理想主義 + 內斂 + 直覺強）
- **核心特質**：
  - 理想主義到近乎天真，但被打擊時也最快學會
  - 慢熱，第一次見面通常不主動
  - 被逼急時思路最清晰（壓力下的能力者）
  - 對不公義有強烈反應，會直接衝撞
- **怪癖**：
  - 緊張時會無意識摸自己的左手腕（母親留下的銀鐲位置）
  - 想事情時會抿嘴
  - 喝茶非常慢
- **口頭禪**：
  - 「**這條絲，斷得不對。**」（緣命絲讀到異常時）
  - 「**異議！**」（庭審反對時）
  - 「我得親自確認。」

### 背景
- 6 歲時母親「言瑤」失蹤（官方紀錄為被綁架後遭殺害），父親在他 14 歲時病逝
- 17 歲考入「玄律學苑」（律都最高律師學府）
- 20 歲畢業，師從「雲息」進入雲息律所
- 22 歲（Game 1 開始）獨立辦案

### 能力：緣命絲（Yuan-Ming-Si）
- **本質**：能看見人與人之間的隱形絲線
- **顏色判讀**：
  - 金絲：愛戀（粗細＝強度）
  - 赤絲：仇恨
  - 墨絲：血債（曾傷害對方至危及性命）
  - 銀絲：師徒
  - 青絲：同袍／戰友
  - 灰絲：交易關係
  - 斷絲：曾有強連結但已斷裂
- **限制**：
  - 必須直接看到當事人（不能透過影像）
  - 亡者的絲會逐漸褪色
  - 過度使用會頭痛、視線模糊（消耗精神）
  - 對自己看不見（除了 Game 3-1 揭示的「鏡像反射」可看母親）
- **真實起源**（後期揭示）：母親言瑤在他 6 歲時種下的「封印守護異能」

### 角色弧

| 階段 | 狀態 | 關鍵變化 |
|------|------|----------|
| Game 1 開頭 | 天真新銳律師 | 不知主線陰謀 |
| Game 1 結尾 | 失去師父 | 立志找回真相 |
| Game 2 開頭 | 成熟律師 | 學會與對手合作 |
| Game 2 結尾 | 被誣陷入獄 | 跌入谷底 |
| Game 3 中段 | 找回母親 | 身世解放 |
| Game 3 結尾 | 守護者 | 終極辯論者 |

### 對白風格
- **句長**：中等。情緒高漲時會變短促有力
- **修辭**：常用反問、排比；不愛用比喻
- **詰問模式**：先承認對方部分立場，再切入矛盾（「您說的有道理，但是 ——」）
- **情緒崩潰時**：句子斷裂，「我……我做不到，但是……」
- **庭審勝利時**：「真相，就在這裡。」

### 立繪需求
參見 `AI生圖_Prompt包.md` 1.1 節

### 設計筆記（給編劇／導演）
- 別把他寫成「天才神探」 — 他的優勢是**死磕**而非智商
- 保留缺陷：常常猶豫、會後悔自己的選擇
- 與靈墟的關係：兄妹般，**不要**寫成戀愛
- 與霜訣明的關係：宿敵→摯友，**互相尊重的男子情誼**
- 對母親：未解的童年創傷，提到母親時聲音會變

## 02. 靈墟（助手）

### 基本資料
- **姓名**：靈墟（Ling Xu，「靈魂的虛境」）
- **族裔**：靈族
- **年齡**：16→18→20
- **生日**：律紀元 184 年・冬至（最強招魂日）
- **出生地**：青澗山靈族山門
- **職業**：見習招魂師 → 正式招魂師（Game 2 後）
- **所屬**：青澗山靈族山門（精神歸屬）/ 言衡的助手

### 外型
- **身高**：155cm（嬌小）
- **體型**：瘦削，看起來脆弱
- **髮**：銀白長髮過腰，兩側各編一條小辮，月牙銀飾
- **眼**：淡銀藍色，幾乎發光
- **膚**：蒼白透明感（靈族特徵）
- **服裝**：
  - **平時**：白色與淡藍中華風袍，雲紋，銀鈴流蘇袖
  - **正式招魂**：純白巫袍，戴銀冠
  - **私下**：簡單藍裙

### 個性
- **MBTI**：ENFP（外向 + 直覺 + 感性 + 隨性）
- **核心特質**：
  - 天真但意志強（決定的事不會放棄）
  - 對食物有迷之熱情（**吃貨設定**）
  - 對死亡的態度比常人輕鬆（職業使然）
  - 容易害怕活人（蜘蛛、雷聲）但不怕鬼
- **怪癖**：
  - 看到食物會口水（漫畫式呈現）
  - 緊張時會碰自己的銀鈴飾品
  - 招魂前必須喝一口冷水
  - **最愛食物**：律都「魂火餃」（辣到能讓鬼也流淚的鍋貼）
- **口頭禪**：
  - 「衡哥！這個能吃嗎？」
  - 「我來招！」
  - 「魂火餃 …… 救命 ……」（極度疲倦時）

### 背景
- 出生於青澗山靈族山門，姊姊「靈寂」是山門繼承人
- 12 歲開始招魂訓練
- 14 歲時姊姊「死亡」（屍體未尋，過 7 日上限無法招魂）
- 16 歲下山，因為「想找到當年姊姊死的真相」
- 在歌劇院案（1-2）遇見言衡，成為夥伴

### 能力：招魂
- **基礎招魂**：5 分鐘以內，必須亡者死亡 7 日內
- **進階招魂**（Game 2 後）：能招特定指定亡者
- **大招魂**（Game 3 後）：能短暫召喚多年前亡者，但消耗極大

### 角色弧

| 階段 | 狀態 | 關鍵變化 |
|------|------|----------|
| Game 1-2 登場 | 見習生，找姊姊 | 失敗但找到夥伴 |
| Game 1-5 | 開始懷疑神諭 | 招魂被神諭力量干擾 |
| Game 2-2 | 信仰危機 | 招魂被破壞，懷疑自己職業 |
| Game 3-3 | 復仇 | 揭穿姊姊真兇 |
| Game 3-5 | 大成 | 成為招魂體系領袖 |

### 對白風格
- **句長**：短，情緒外露
- **語助詞**：很多（「啦」「嘛」「呀」）
- **與言衡**：直呼「衡哥」
- **與霜訣明**：怕他但會反嗆「冰冰先生」
- **嚴肅模式**（招魂時）：突然變沉穩低音，像是被附身

### 立繪需求
參見 `AI生圖_Prompt包.md` 1.2 節

### 設計筆記
- **避免賣萌過頭** — 她有強烈的內在意志，不是花瓶
- 招魂時的「靈墟模式 vs 嚴肅模式」反差是核心魅力
- 與言衡是兄妹情，**絕對不戀愛**
- Game 3-3 殺姊兇手揭曉那段是她最動人的爆發

## 03. 霜訣明（對手檢察官）

### 基本資料
- **姓名**：霜訣明（Shuang Jue-ming，「霜的決斷之明」）
- **族裔**：半精靈（人母 + 精靈父）
- **年齡**：26→28→30
- **生日**：律紀元 174 年・冬至
- **出生地**：玄律城・西區（沒落精靈貴族區）
- **職業**：檢察官 → 大檢察官（Game 3 結尾）
- **所屬**：律廷檢察院

### 外型
- **身高**：182cm
- **體型**：修長，類精靈體質
- **髮**：銀金色長髮（混血特徵），梳得整齊向後
- **眼**：冰藍色，銳利
- **耳**：略尖（半精靈特徵，常被人嘲笑）
- **服裝**：
  - **檢察袍**：高領深紅黑配色，銀鏈飾，金繡袖口，白領巾
  - **私下**：精靈式絲質襯衫，簡約

### 個性
- **MBTI**：ENTJ（外向 + 直覺 + 思考 + 判斷）
- **核心特質**：
  - 表面冷峻、骨子裡熱血
  - 完美主義到病態（連桌上紙張都要對齊）
  - 視「絕對勝率」為自我價值（Game 1 的核心動機）
  - 半精靈身分是創傷 — 在精靈中被排擠
- **怪癖**：
  - 不喝普通茶，只喝精靈式蜂蜜露
  - 不吃肉（精靈飲食習慣）
  - 整理檔案時會用魔法折射弄出「冰鏡」反射光
  - 私下其實會養貓（不能告訴別人）
- **口頭禪**：
  - 「無趣。」（對辯方主張的常見開場）
  - 「異議。」（不會像言衡那樣大喊，是低聲的）
  - 「真相只有一個 — 而且通常不在辯方那邊。」（Game 1）
  - 「這次換我。」（Game 2 結尾，跨陣營經典台詞）

### 背景
- 父親是精靈貴族「霜系」末裔，母親是人族商家女
- 因混血身分，被精靈族視為「不純」，被人族視為「異類」
- 14 歲考入律廷，創下最年輕檢察官紀錄
- 從未敗訴，直到言衡出現
- 父親後期被歿言子拉攏（個人主線）

### 能力：冰鏡
- **本質**：能將魔法痕跡凝固成可視冰像，是合法執照的灰籙術
- **用途**：
  - 重現案發現場的魔法殘留
  - 將證物的內部結構視覺化
  - 庭審時放映給法官與旁聽
- **限制**：只能呈現過去 24 小時內的魔法痕跡

### 角色弧

| 階段 | 狀態 | 關鍵變化 |
|------|------|----------|
| Game 1-3 登場 | 高冷對手 | 第一次嘗到敗訴 |
| Game 1-5 | 不情願的合作 | 開始懷疑檢方體系 |
| Game 2-1 | 私下分享情報 | 半合作 |
| Game 2-4 | 為言衡的師父辯護 | 立場互換 |
| Game 3-1 | 為言衡辯護 | 摯友確認 |
| Game 3-5 | 副律師 | 共戰終局 |

### 對白風格
- **句長**：精緻短句，每字斟酌
- **修辭**：愛用法律術語（「依《律典》第三百二十條 ——」）
- **冷諷**：「真有趣」、「無稽之談」、「請見證據」
- **私下**（與言衡熟後）：略軟，會開玩笑
- **情緒崩潰**：保持冷靜但會嗆出聲（極少見）

### 立繪需求
參見 `AI生圖_Prompt包.md` 1.3 節

### 設計筆記
- **不要寫成御劍 2.0** — 他的痛點是「混血身分」而非「父親死亡」
- 與言衡的友誼建立要慢，Game 1 全程對立
- 私下養貓的設定是給玩家的甜點 — 在 Game 2 偶然撞見的搞笑場景
- Game 2-4 那句「這次換我為你辯護」要做成名場面

- 表弟「砂狼」是 Game 2-1 案的被告
- 與言衡相識於案 1-1 警備隊辦公室

### 能力：血氣追蹤
- **本質**：用嗅覺感知施暴痕跡與血脈關係
- **用途**：
  - 找出隱藏的兇器
  - 辨識血親關係
  - 嗅出魔法殘留的「氣味」
- **限制**：在魔法濃度高的地方會被干擾；雨天能力減弱

### 角色弧

| 階段 | 狀態 | 關鍵變化 |
|------|------|----------|
| Game 1-1 登場 | 排擠的偵探 | 與言衡互信 |
| Game 1-4 | 正式夥伴 | 加入主角陣營 |
| Game 2-1 | 利益迴避困境 | 為表弟掙扎 |
| Game 3-3 | 領導獸人警備 | 種族崛起 |
| Game 3-5 | 證人 | 為獸人發聲 |

### 對白風格
- **句長**：短促，常常是單詞或片語
- **語氣詞**：「嗯」「哦」「嘿」很多
- **粗話**：偶爾，但不多（「他媽的」「靠」）
- **正式時**（庭審報告）：突然變得字正腔圓，反差感
- **與言衡**：稱「小子」，後期改稱「言律師」

## 05. 沉律（法官）

### 基本資料
- **姓名**：沉律（Chen Lü，「沉穩之律」）
- **族裔**：精靈族
- **年齡**：197 歲（精靈中年）
- **職業**：律廷主庭法官
- **所屬**：律廷

### 外型
- **身高**：178cm
- **體型**：瘦削老人型
- **髮**：銀白色長髮，向後束起
- **鬚**：白色長鬚到胸口
- **耳**：明顯尖耳
- **眼**：翠綠色，有皺紋
- **服裝**：深紫色法袍，金綠繡花，高立領，闊袖

### 個性
- **核心特質**：
  - 表面威嚴實則隨和
  - 容易被檢辯雙方耍得團團轉
  - 心地善良，會給辯方機會
  - 對「真相」有近乎執著的追求
- **口頭禪**：
  - 「肅靜！」

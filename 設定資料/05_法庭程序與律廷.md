# 法庭程序與律廷 — 司法體系設定

> 諸界之衡的庭審機制是遊戲核心玩法。本文件詳述法庭程序、角色、規則、玩家可用動作。

---

## 1. 律廷概述

### 1.1 諸界律廷
- 衡律帝國最高司法機關
- 駐地：玄律城中央，白色大理石建築
- 處理跨族案件、重大刑案、跨部門爭議

### 1.2 律廷組織

```
                    大法官
                       │
       ┌──────────────┼──────────────┐
       │              │              │
   主庭法官        檢察院         律師工會
   （沉律）       （院長：玉裁）   （會長：言止）
       │
   各副庭法官
```

### 1.3 各級法庭
| 級別 | 處理案件 | 在故事中 |
|------|----------|----------|
| 律廷主庭 | 重大刑案、跨族 | **本作所有案件** |
| 律廷副庭 | 一般刑案 | 不處理 |
| 地方律所庭 | 民事 | 不處理 |
| 神諭法堂 | 涉神諭案件 | 案 1-5、案 3-4 |

- 旁聽席兩側階梯式
- 後方大銅門（莊嚴）

## 3. 庭審制度

### 3.1 三日審制
- 仿原作《逆轉裁判》設定
- 初審至多三日（重大案件可延長）
- 每日庭審後有調查時段（玩家可離場調查）

### 3.2 庭期分配（標準刑案）
| 日 | 內容 |
|----|------|
| 第一日 | 開庭、檢方陳述、第一證人證詞與詰問 |
| 第二日 | 第二證人、補充證據、辯方質詢 |
| 第三日 | 終局證人、最終陳詞、判決 |

### 3.3 大型案件（如 3-4、3-5）
- 可延長至 7 日
- 需大法官批准
- 通常涉及國家層級議題

---

## 4. 庭審角色

### 4.1 法官
- 主持庭審、維持秩序
- 採信／否決證據
- 最終裁決
- 本作主要法官：**沉律**（精靈長老）

### 4.2 檢察官
- 代表國家提起公訴
- 證明被告有罪
- 提交證據、傳喚證人
- 主要對手：**霜訣明**（半精靈）

### 4.3 辯護律師
- 為被告辯護
- 質詢證人、提出反證
- 揭穿矛盾
- **玩家視角：言衡**

### 4.4 證人
- 由檢辯雙方傳喚
- 須在「真誓」下作證（生者）或招魂作證（死者）
- 偽證屬重罪

### 4.5 旁聽
- 公開審判，民眾可旁聽
- 不得發言
- 重大案件可有「旁聽長老」（如七族代表）

## 5. 玩家可用動作（庭審 UI）

### 5.1 基本動作
- **詰問**：要求證人就某句證詞補充
- **異議**：對檢方或證人主張反對
- **揭穿**：指出證詞中的具體矛盾（玩家最常用）
- **提出證物**：將證物與證詞對應
- **使用緣命絲**：讀取人際關係（消耗精神）

### 5.2 詳細用法

#### 詰問（QUESTION）
- 點選證詞中的具體句子
- 證人補充細節（可能露出更多矛盾）
- 不消耗信用值

#### 異議（OBJECTION）
- 對某句證詞主張「不合理」
- 可單獨使用（無需證物）
- 失敗會扣信用值
- **不大喊**（霜訣明風格）或**大喊**（言衡風格）

#### 揭穿（EXPOSE）
- 點選矛盾句子 + 提出對應證物
- 成功則證人崩潰、推進劇情
- 失敗扣信用值
- 通常是「異議」的具體形式

#### 提出證物（PRESENT）
- 將某件證物作為論點輔助
- 可在不點選具體句子時使用
- 失敗扣信用值較少

#### 緣命絲（FATE THREADS）
- 在證人席讀取證人關係
- 顯示對應顏色絲線
- 過度使用會頭痛（一場庭審限 5 次）
- Game 1 法庭不認可，Game 2 後逐漸認可

### 5.3 信用值系統
- 開庭時 100%
- 失誤扣 5–15%（依嚴重度）
- 0% = 敗訴
- 部分案件勝訴需保留 ≥ 50%（高難度成就）

## 6. 證據規則

### 6.1 證據登記
- 開庭前，辯方／檢方必須登記證物
- 登記表格存於律廷
- 未登記證物原則上不可使用，**但**：
  - 調查階段發現的「新證物」可追加
  - 法官可酌情接受

### 6.2 證據種類

| 類型 | 例子 | 可信度 |
|------|------|--------|
| 物證 | 兇器、文件 | 高 |
| 鑑識報告 | 警備隊報告 | 中（可能有錯） |
| 招魂證詞 | 亡者證言 | 高（除非真誓被破） |
| 神諭 | 神之意 | 中（爭議） |
| 緣命絲讀數 | 言衡的能力 | 低→中（隨故事推進） |
| 直接目擊 | 證人證詞 | 視證人可信度 |

### 6.3 偽證罪
- 故意作偽證 = 重罪
- 偽造證物 = 重罪
- 通常會被當庭逮捕

---

## 7. 律師工會

### 7.1 組織
- 全國律師管理機構
- 會長：**言止**（人族，雲息舊友）
- 處理律師執照、爭議、培訓

### 7.2 律師執照
- 需通過「玄律學苑」畢業
- 律廷面試
- 每 5 年續證

### 7.3 律師守則
- 不得偽造證據
- 不得明知有罪仍辯為無罪（爭議性，多半睜一隻眼）
- 不得收受不當報酬
- 違反 → 暫停執照→ 終身禁業

---

## 8. 檢察院

### 8.1 組織
- 院長：玉裁（精靈，老檢察）
- 旗下檢察官分三級
- 霜訣明是「特等檢察官」（少有的最高級）

### 8.2 檢察官的爭議
- 「絕對勝率」是榮譽，但常導致冤案
- 霜訣明的初期設定是這個體系的縮影
- Game 2-1 後，他開始質疑這套價值

---

## 9. 各案的庭審特殊機制

### 9.1 案 1-1
- 教學案，無檢察官（警備隊代理）
- 三段矛盾揭穿

### 9.2 案 1-3（霜訣明登場）
- 檢察官全面壓制
- 教玩家「強對手如何應對」

### 9.3 案 1-5（神諭審理）
- 神諭官陪審（除沉律外加 3 名神諭官）
- 證據規則更嚴

### 9.4 案 2-2（真誓被破）
- 招魂證詞首次失效
- 玩家面對「招魂無效」的困境

### 9.5 案 2-4（雙線並進）
- A 案、B 案同時開庭
- 玩家在兩位律師之間切換

### 9.6 案 3-1（言衡被告）
- 言衡在獄中遠端指揮
- 霜訣明擔任辯護律師
- 視角異常

### 9.7 案 3-4（諸神之審）
- 七族長老共同審判席
- 法律 vs 哲學辯論
- 不需物證，但需歷史證據

### 9.8 案 3-5（最終法庭）
- 「界靈」為法官（無形體）
- 七場辯論主題
- 全部前案的證物都可用

## 11. 庭外調查機制

### 11.1 調查時段
- 每日庭審結束後
- 玩家可前往多個地點調查
- 收集證物、與證人對話

### 11.2 可調查地點
- 案發現場
- 律所（大本營）
- 警備隊（找雷狼）
- 拘留所（會被告）
- 證人住處（部分需許可）
- 律廷檔案室（查資料）

### 11.3 調查的限制
- 部分地點需特殊許可
- 緣命絲可在調查時對證人使用（精神消耗）
- 時間有限（每日結束會強制進入下一日庭審）

## 12. 設計筆記

### 12.1 法庭節奏
- **詰問→異議→揭穿→證物→反轉**：每個矛盾的標準節奏
- 不要連續揭穿三個矛盾無喘息
- 中間穿插法官、霜訣明的反應戲

### 12.2 視覺戲劇感
- 異議時的鏡頭推近
- 揭穿時的證物特寫
- 證人崩潰時的表情變化（5 種表情用滿）

### 12.3 公平性
- 每個矛盾必有「玩家可在前期收集到的證物」
- 不要要求玩家「神來之筆」
- 卡關時系統可給輕微提示（信用值不扣）

### 12.4 律廷的可改革性
- Game 1：律廷被神諭院制衡，無力
- Game 2：律廷與檢察院內部分裂
- Game 3：律廷重生，成為新體制核心

---

## 13. 庭審後流程

### 13.1 勝訴後
- 被告當庭釋放
- 真兇被當庭逮捕（如有）
- 短暫終幕場景（律廷外）
- 進入下一案

### 13.2 敗訴後（game over）
- 黑屏
- 言衡的內心獨白（後悔、迷茫）
- 重新讀檔選項

### 13.3 真相未完全揭露
- 部分案件刻意留白
- 主線伏筆會在後續案件揭露
- 這不是 game over，而是劇情設計

# 術籙制 — 魔法系統設定

> 諸界之衡的魔法是「法律規範下的有照行為」。本文件詳述魔法分類、施法機制、犯罪用途、與庭審推理的結合。

---

## 1. 核心概念：魔法即法律物

在衡律帝國，魔法不被視為神秘力量，而是「**可登記、可規範、可追蹤**」的法律規範行為。

每位施法者必須向「術籙令所」註冊：
- 種族
- 可施法等級（白／灰／黑）
- 已習得術式清單
- 執照編號

無照施法 = 違法。**這是大量案件的犯罪根源。**

## 2. 三類魔法

### 2.1 白籙（合法・無需執照）

| 類別 | 例子 | 顏色 |
|------|------|------|
| 照明 | 光明術、夜視術 | 白光 |
| 治療 | 小傷癒合、解毒 | 綠光 |
| 通訊 | 短距傳音 | 藍光 |
| 輔助 | 清潔、加熱 | 黃光 |

**特徵**：
- 任何人都可以學習
- 不留下危險痕跡
- 是日常生活的一部分

**例**：歌劇院燈光、律所茶水加熱、雷狼的鑑識照明

### 2.2 灰籙（限制・需執照）

| 類別 | 例子 | 顏色 |
|------|------|------|
| 變形 | 改變外貌 | **紅色**（案 1-1 關鍵） |
| 催眠 | 短時心理暗示 | 紫色 |
| 追蹤 | 標記他人 | 橙色 |
| 戰鬥 | 元素術 | 各色 |
| 鏡像 | 視覺呈像（霜訣明專長） | 冰藍 |

**特徵**：
- 需通過律廷考試取得執照
- 每次使用需在「術籙日誌」登記
- 警備隊會抽查日誌

**執照種類**：
- A 類：戰鬥（軍警）
- B 類：商業（變形演員、商業催眠師）
- C 類：個人（學者、私人偵探）

### 2.3 黑籙（非法）

| 類別 | 例子 | 後果 |
|------|------|------|
| 操控心智 | 強制服從 | 死刑 |
| 奪取生命 | 直接致命術 | 死刑 |
| 改寫記憶 | 抹除特定記憶 | 終身監禁 |
| 死後咒 | 影響亡者（破壞真誓） | 死刑 |
| 血祭 | 用生命換能量 | 死刑 |
| 封印解放 | 解封被封印之物 | 死刑（特殊案） |

**特徵**：
- 學習即犯罪
- 痕跡難消除（黑色或暗紫色）
- 通常與重大刑案相關

**重要設定**：
- **歿言子是黑籙頂級術士**
- 歸源派的核心力量是黑籙

## 3. 施法痕跡 — 「術紋」

### 3.1 基本概念
每次施法在空氣或物體上留下「**術紋**」（魔法殘留圖案）。
- **白籙**：白／黃／綠光，散逸快（1–6 小時消失）
- **灰籙**：紅／紫／橙等鮮豔色，殘留中等（6–48 小時）
- **黑籙**：黑或暗紫，殘留長（數天至數週）

### 3.2 術紋鑑識
- **術紋鑑識官**：警備隊專業職位
- 用「術紋鏡」檢測殘留
- 可判斷：
  - 術式類型
  - 施法時間（誤差 ±1 小時）
  - 部分情況下能識別施法者（高階鑑識）

### 3.3 術紋偽造（重要犯罪手法）
- 高階魔法師可：
  - 偽造別人的術紋（栽贓）
  - 抹除自己的術紋
  - 改變術紋顏色（部分情況）

**案件中的應用**：
- 案 1-1：阿諾的「紅色魔紋」是變形術反應，被栽贓為開鎖術
- 案 2-2：賄賂帳本的署名魔紋被微調

## 4. 魔器（Magical Artifact）

### 4.1 基本概念
- **魔器**：矮人鑄造的魔法物品
- 受嚴格管制，每件都有編號
- 大型魔器需登記在律廷魔器局

### 4.2 魔器分類

| 等級 | 例子 | 持有限制 |
|------|------|----------|
| 一級 | 照明球、簡單通訊符 | 自由 |
| 二級 | 戰鬥武器、小型機關 | 需登記 |
| 三級 | 司辰魔懷錶（案 1-1）、術紋鏡 | 需登記＋執照 |
| 四級 | 古卷、神諭法器 | 國家管制 |
| 五級 | 諸界共律相關物 | 機密 |

### 4.3 知名魔器

- **司辰魔懷錶**（案 1-1）：能精確測量魔法殘留時間，矮人鏗匠最高傑作
- **啟言筆**（案 1-5）：神諭官專用，只能由龍裔血脈使用，刺穿物可釋放神諭力量
- **歲輪杖**（案 2-4）：神諭副院長的法器
- **冰鏡**（霜訣明）：將魔法痕跡凝固成可視冰像
- **諸界共律殘卷**：終極魔器，被分為四片散藏

### 5.2 考照流程
1. 學苑畢業
2. 提交履歷至「術籙令所」
3. 參加術紋示範
4. 通過律廷面試
5. 取得執照（每 5 年續證）

## 6. 魔法在庭審中的證據力

### 6.1 可被接受的魔法證據
- 術紋鑑識報告（白／灰籙的識別）
- 冰鏡呈像（霜訣明的特長）
- 招魂證詞（靈族專屬）
- 緣命絲讀數（言衡的，但需要其他證據佐證 — Game 1 時不被法庭認可，Game 2 中段才開始接受）

### 6.2 不被接受
- 預言（神諭體系除外）
- 心理推測
- 個人「直覺」

### 6.3 異能證據的爭議
- 緣命絲、緣命絲、龍裔預言、影族影行 — 這些都在「異能證據能否成立」的灰色地帶
- Game 2-2 的「真誓被破壞」案是這場爭議的轉折點

## 7. 各案中的關鍵魔法元素

### 7.1 案 1-1 變形術（灰籙）
- 阿諾以變形術變成林晨
- 紅色術紋是變形術反應，不是開鎖術
- **教學案的核心**：教玩家「術紋顏色可以解讀」

### 7.2 案 1-2 鏡像幻術（灰籙）
- 幻夜在主舞台用鏡像分身播放表演
- 真身溜到後台殺人
- **教學**：影像紀錄不一定是真人

### 7.3 案 1-4 延時術籙（灰籙進階）
- 7 小時前布置好的爆破，自動引爆
- 製造完美不在場證明
- **教學**：時間詭計

### 7.4 案 2-2 死後謊言咒（黑籙頂級）
- 歿言子破壞真誓的核心手段
- 標誌《諸界共律》核心機制崩壞
- **主線轉折**

### 7.5 案 2-3 赤蓮黑籙刺青（黑籙）
- 標記人柱的古老術式
- 漆夜父親（白籙轉化）vs 赤絹（黑籙刻入）
- **揭示主線**：人柱真相

### 7.6 案 3-2 記憶魔法（黑籙）
- 改寫言衡童年記憶
- 證明母親是被綁不是被殺
- **個人主線揭示**

## 8. 魔法戰鬥規則（給未來動作場面）

### 8.1 戰鬥類魔法的限制
- 律都市區內禁止使用 A 類戰鬥術（除非警備隊）
- 自衛例外，但事後必須報告

### 8.2 法庭內禁術
- 庭審期間，**任何戰鬥術都禁止**
- 違者立即逮捕
- 唯一例外：辯方／檢方為證明案件演示（需事先申請）

### 8.3 重要戰鬥場面
- 案 1-3 結尾：赤絹當庭逃脫
- 案 2-3 結尾：赤絹再度逃脫
- 案 3-3：攻入神諭院（隱含戰鬥但以言衡視角呈現對話與調查）
- 案 3-5：純辯論，無物理戰

## 9. 設計筆記

### 9.1 魔法不要當 Deus Ex Machina
- 每個魔法的限制必須清楚
- 不要在最後一刻發明新術式解決問題
- 玩家應能依設定推理結局

### 9.2 術紋顏色清單（記憶用）
| 顏色 | 術類 |
|------|------|
| 白 | 白籙基礎 |
| 黃 | 白籙輔助 |
| 綠 | 治療 |
| 藍 | 通訊 |
| 紅 | 變形 |
| 紫 | 催眠 |
| 橙 | 追蹤 |
| 冰藍 | 鏡像 |
| 黑 | 黑籙基礎 |
| 暗紫 | 黑籙頂級 |
| 金 | 神諭力量 |

### 9.3 魔法相關的對白用語
- 「我想登記一個 ⋯⋯」（執照申請）
- 「術籙日誌呢？」（庭審質問）
- 「這術紋是 ⋯⋯ ？」（鑑識常用）
- 「黑籙！」（震驚反應）
- 「無照施法！」（指控）

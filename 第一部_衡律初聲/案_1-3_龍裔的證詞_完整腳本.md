## J. 分支與重試機制

### J.1 失誤回饋

| 失誤類型 | 回饋 | 處罰 |
|----------|------|------|
| 詰問選錯句子 | 霜訣明：「言律師 — 無趣。」 | 信用值 -10% |
| 提錯證物 | 霜訣明嗤笑 | -10% |
| 緣命絲過頻 | 言衡頭痛、靈墟扶他 | 強制冷卻 |
| 錯選赤絹的對應方式 | 庭審日 3 配合度降低 | 流程不變但細節改 |

### J.2 道德分支（赤絹的選擇）

| 選擇 | 結果 |
|------|------|
| **答應赤絹逃** | 庭審日 3 主動配合 + 順利逃脫，霜訣明嚴厲 |
| **拒絕，讓她受審** | 庭審日 3 半合作 + 反抗逃脫，言衡仍勝訴但更費力 |
| **不答應但不阻止** | 庭審日 3 主動配合 + 爽快逃脫，霜訣明意味深長 |

【💡 此分支將影響 Game 2-1 赤絹再度出場時的態度】

### J.3 高難度路線

若玩家在調查日 1 未發現「影族刺青殘留」：
- 庭審日 3 無法直接連結赤絹
- 必須在影族貧民窟做更多調查
- 赤絹更難說服
- 信用值流失更快

### J.4 案件分支結局

| 結局 | 達成條件 | 內容 |
|------|----------|------|
| **真結局**（推薦） | 揭穿全部 + 緣命絲使用 ≥ 3 次 + 赤絹道德選擇任一 | 燁姬無罪、赤絹逃、闕影定罪、霜訣明伏筆、歸源派系統提及 |
| **次佳結局** | 揭穿主要 + 赤絹未說服 | 燁姬無罪、闕影定罪，但赤絹反殺脫逃 |

## M. 設計筆記（給編劇／關卡設計）

### M.1 霜訣明登場的關鍵
- 不要讓他「打不中要害」 — 他要真的強
- 庭審日 1 言衡幾乎敗 = 玩家感受到對手的可怕
- 庭審日 3 終局時，他承認言衡的勝利但留伏筆
- 「我會記住你」要做成名場面（鏡頭定格、音樂停）

### M.2 燁姬的沉默設計
- 沉默不是弱 — 是貴族風骨
- 燁姬全案說話極少，但每一次抬眼、含淚、點頭都要有戲
- 終幕首次完整開口要做高潮
- 「龍裔規矩 — 真相揭露之後，方可發聲」是她的核心人設

### M.3 招魂異常的視覺呈現
- 與案 1-2 的「正常招魂」對比
- 銀色光球**不穩定、扭曲、黯淡**
- 真夕霓的形象**半透明且閃爍**
- 聲音帶**重重迴音**
- 對白**斷斷續續**

### M.4 赤絹首次登場的衝擊
- 名字「赤絹」要單獨一個鏡頭
- 影行能力（融入陰影）的特效要強
- 角色立場曖昧 — 不是全惡，是被洗腦的悲劇
- 道德選擇要讓玩家真感受困難

### M.5 闕影的反派塑造
- 表面諂媚、骨子裡冷血
- 庭審日 3 失言「代表的勢力」是揭示主線的鑰匙
- 不要讓他變大反派 — 他只是中層棋子
- 結局不悔悟，符合歸源派「忠誠」設定

### M.6 影族貧民窟的氛圍
- 暗紅色基調
- 警備隊不入 — 顯示帝國的歧視
- 暗市商人的恐懼是社會議題的縮影
- 為 Game 3 影族議題終局鋪墊

### M.7 緣命絲在本案的進化
- Game 1-1：教學
- Game 1-2：第一次「斷絲變墨絲」名場面
- Game 1-3：**第一次被檢方否定**（霜訣明壓制）— 玩家感受到「異能不是萬能」

### M.8 與案 1-2 的對比
- 1-2：情殺案、密室、招魂正常
- 1-3：政治案、種族議題、招魂異常、有對手檢察官
- 1-3 開始走向「主線陰謀導向」案件結構
